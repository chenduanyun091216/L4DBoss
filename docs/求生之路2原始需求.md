# 1.角色

你是一位高端python变成开发人员，尤其善于通过python开发漂亮的GUI界面

# 2.整体目标

现在需要开发一款求生之路2（Left 4 Dead 2）游戏的mod管理工具，需要自动对用户选择的目录下的vpk文件进行解析，能够通过文件名对应的id编码去steam平台获取mod的名字及其他描述信息，能够将mod进行分类（分类方式参考steam创意工坊），同时需要解析vpk文件，当选择多个mod存在冲突时需要给出提示，最终将用户选择的mod写入addonlist.txt文件中，整个项目需要一个GUI页面支持

# 3.具体任务

## 3.1 页面布局

## 3.2 功能

### 3.2.1 菜单栏

- 菜单栏图标鼠标悬浮时会有一个功能提示，其中：

> 加号图标：点击选择mod存放的目录
>
> 刷新图标：刷新mod（只刷新新增的mod）
>
> 重置图标：重新获取所有mod（mod初始化）
>
> 拉取图标：从Steam上获取对应的mod信息，拉取时间一般较长

- 点击菜单栏`加号图标`打开目录选择对话框，用户选择对应mod存储目录，后续读取vpk文件则依托于该目录，同时需要把该目录记录下来，只要用户没有重新选择，该目录就不变

- 默认情况下，mod的信息从文件夹中的vpk获取，mod的图片为文件夹中同名的jpt图片，当点击了菜单栏中的拉取图标时则通过vpk的名称（即对应mod的id）去steam上获取对应的信息并覆盖，相关数据包含：名称、创作者、订阅量、星级

### 3.2.2 信息展示栏

- 在展示的mod卡片上点击则将其激活，并打上“激活”的标签提示，颜色标绿
- 如果出现冲突，则打上“mod冲突”的标签提示，颜色标红

### 3.2.3 功能栏

- 对于存在冲突mod时，下方展示存在冲突的mod数，同时其支持点击，点击查看具体冲突mod情况，以弹框展示，冲突的mod以卡片形式展示
- 点击保存后给出弹框，让用户输入名称，确定后将对应的数据本地存储，并写入addonlist.txt文件中
