### 关键 bug 修复（0xC0000409 崩溃）
拆分 MainWindow 时把方法抽成**模块级函数**再 `MainWindow.xxx = xxx` 绑定。但 `closeEvent/resizeEvent/showEvent`（main_window_events.py）体内用了无参 `super()`，脱离类定义后 `__class__` 闭包丢失，运行时抛 `RuntimeError: super(): __class__ cell not found`；被 PyQt 的 C++ 事件分发捕获后表现为进程崩溃 `STATUS_STACK_BUFFER_OVERRUN (0xC0000409)`，无 Python traceback。
**修复**：这些方法内 `super()` 改为 `super(type(self), self)`（单继承等效，无需 import MainWindow 避免循环）。
**教训**：用"模块级函数 + 绑定"方式拆分 PyQt 类方法时，凡是含无参 `super()` 的方法（事件回调 closeEvent/resizeEvent/showEvent/eventFilter 等）必须改用 `super(type(self), self)`，否则运行时崩溃。

### 浅色主题混入深色元素（已修复）
根因：原单文件 app.py 中 `_apply_style` 用 `global ACTIVE_THEME; ACTIVE_THEME = self._theme` 修改模块全局主题变量，而 `theme_color()` 读的就是这个全局变量。拆分后该方法在 `main_window_build.py`，`from .theme import *` 只是把 `ACTIVE_THEME` 作为**值快照**导入本模块，`global` 只改了本模块副本，`theme.py` 的 `ACTIVE_THEME` 始终为 "dark"，导致切换浅色后所有用 `theme_color()` 绘制的组件仍用深色调色板。
**修复**：`main_window_build.py` 加 `from . import theme`，把赋值改为 `theme.ACTIVE_THEME = self._theme`。
**教训**：拆分后凡是通过 `from X import *` 引入的"可变全局状态"，不能用 `global` 在本模块改它，必须显式改 `X.var`。
